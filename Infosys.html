Email Automate Pro

A centralized Google Apps Script web application designed to streamline, standardize, and track outbound email communications for loan processing and underwriting teams. Quickly generate scenario-specific emails, attach screenshots, append dynamic signatures, and log all communications automatically.

Key Benefits

Massive Time Savings

Eliminates the need to draft repetitive emails from scratch. Select a scenario, input details, and the tool does the rest.

Standardized Communication

Ensures all emails follow a consistent, professional format with pre-approved introductory and closing statements.

Reduced Human Error

Automatically routes emails to correct departments and CCs stakeholders based on centralized spreadsheet rules.

Seamless Evidence Attachment

The custom "Snip Zone" allows users to paste screenshots directly from their clipboard into the email body inline.

Automated Audit Trail

Every sent email is silently logged into a central database with a timestamp, user ID, and comprehensive loan details.

Technical Features

  • Dynamic Email Routing: Pulls "To" and "CC" lists dynamically from Google Sheets based on correction type.
  • Scenario Templates: Auto-adjusts subject lines, required form fields, and body text per category.
  • Rich Media Support: Supports inline base64 image pasting (Content-ID mapping) and PDF attachments.
  • Dynamic Signatures & Preview: Auto-detects active user for HTML signatures and offers a full preview mode before sending.

Database Setup

Tab 1 EmailConfig

Manages dynamic recipient routing and templates. Setup specific columns for To/CC based on Funding, Flips, Mavent Fail, UW Conditions, etc. Uses C1:F2 for standard text blocks.

Tab 2 Requests

Audit log sheet. Expected Headers: Date, Time, User Email, Loan Number, Correction Type, Borrower Last Name, Property Address...

Tab 3 Signatures

Holds user profile data (Email, Name, Title) and HTML templates using {{NAME}} syntax.

Deployment

  1. Open Google Sheet > Extensions > Apps Script.
  2. Paste backend logic into Code.gs.
  3. Create form.html and paste Frontend code.
  4. Deploy > New deployment > Web app.
  5. Execute as: User accessing the web app.
  6. Access: Anyone within org.
  7. Deploy and authorize permissions.

Leave Request Automation

A robust Google Apps Script web application designed to modernize the employee leave request workflow. It combines a user-friendly frontend form with a powerful Sheets backend to automate data entry, prevent duplicate requests, and handle multi-tier email notifications seamlessly.

Core Capabilities

Smart Identification

Automatically identifies the logged-in user and populates their Name and ID, preventing impersonation.

Advanced Validation

Cross-checks inputs to explicitly prevent users from selecting past dates or submitting duplicate requests for the same day.

Automated Comms

Dispatches instant confirmation emails and routes approval/rejection updates with automated CCs to designated managers.

Dynamic Dropdowns

Shifts, Process Types, and Lead assignments are fed directly from Google Sheets, allowing non-technical admins to update options.

Multi-Date Submissions

Users can add multiple consecutive or non-consecutive dates (Full Day / Half Day) in a single form submission, vastly improving UX compared to native Google Forms.

Database Structure

1. "Leads" Directory Sheet

Source of truth for validations.

  • Col A-C: Email, ID, Name
  • Col E & G: Lead Names & Manager CCs
  • Col I & J: Shift & Process Types

2. "Leave Requests" Database

Auto-generated upon first submission.

Timestamp, Email, ID, Name, Shift, Process, Leave Date, Type, Reason, Lead, Status, Status Updated On

Production Dashboard Web App

A dynamic, interactive web application built utilizing Google Apps Script and Google Charts. It serves as a centralized operations hub, securely fetching data from multiple external tracking sheets to visualize key team metrics—such as attrition, billable resources, and LOB status—in a fast, tabbed interface.

Visual Insights

Transforms raw rows into color-coded Google Charts natively.

Multi-Source

Securely aggregates cross-spreadsheet data using Apps Script backend.

Live Filtering

Dynamic date ranges re-calculate all dashboard arrays on the fly.

Zero Infra Cost

Replaces expensive BI tools, hosted 100% on Google Workspace.

Dashboard Modules

  • Attrition Metrics: Visualizes team changes & leaves.
  • Billable / Buffer: Headcount vs. Bench analysis.
  • LOB Status: Resource allocation by Line of Business.
  • Managers Rollup: Comparative stats across management.

Security & Architecture

Hardcoded Remote IDs

The backend script utilizes SpreadsheetApp.openById(). External tracker IDs must be hardcoded in the getDashboardData() function securely.

OAuth Data Scopes

Users accessing the web app must authorize standard Apps Script scopes to allow the script to execute read-operations against the external sheets on their behalf.

Robust Error Handling

Try/Catch blocks ensure the dashboard safely renders fallback error states rather than breaking completely if a manager deletes an external sheet or alters view permissions.

DocAudit Portal AI Integrated

An all-in-one hub designed to standardize document verification for mortgage loans (Non-Del, Flips, Refinances). It combines dynamic conditional checklists, automated personal tracking sheets, and built-in, highly structured prompts designed specifically for AI extraction via Google Gemini.

Standardized AI Prompts

Read-only, optimized instruction sets built into the UI. Click-to-copy standardizes how auditors prompt Gemini for extraction.

Dynamic Checklists

Fetches rules from master sheets based on Loan Type and State. Remote updates return a conditional checklist in seconds.

HTML to Image

Integrates html2canvas to instantly convert fetched HTML data tables into copyable clipboard images for easy sharing.

Auto-Tracker Generation

Checks Drive for a user's personal tracking sheet. If none exists, it duplicates a master template and embeds it via iframe.

Tech Stack & Developer Notes

  • Backend System Google Apps Script (SpreadsheetApp, DriveApp, Session context)
  • Frontend UI HTML5, Tailwind CSS via CDN, Vanilla JavaScript
  • Client Libraries html2canvas (Converts DOM elements directly to Blob images)

Deployment Constraints

  • Requires hardcoding master IDs for Flips, Nondel, and Summary Templates.
  • The iframe URL is appended with ?rm=minimal to hide standard Google Sheet toolbars.
  • The Clipboard API requires the portal to run in a secure HTTPS context.

Escalation & RCA System

A dual-interface solution designed to completely overhaul the logging of operational errors. It bridges custom web forms, Google Sheets databases, and Gmail threading to automate the lifecycle of an Escalation from initial flagging to final Root Cause Analysis (RCA) submission.

1. Escalation Portal

Used by QA/Audit to log errors. Features smart dropdowns powered by `TomSelect.js` and a custom clipboard listener allowing auditors to paste screenshots inline.

  • Auto-logs to central database
  • Converts clipboard images to inline email attachments
  • Dispatches formatted HTML email to target

2. RCA Submission

The follow-up portal for the responsible party. Submits explanations and action plans. Crucially, the backend searches Gmail to thread the response.

  • Auto-updates master status from Pending to Provided
  • Searches Gmail via subject:"{loanNo}"
  • Forces a "Reply All" to keep inboxes clean

Business Value & Impact

Friction Reduction

Ctrl+V image pasting completely eliminates the need to save screenshots as files before uploading them to an email.

Accountability

Hard-logs every timestamp. Eliminates the "I lost the email" excuse via automated time-driven reminder pings.

Standardization

Replaces chaotic, multi-formatted email chains with rigid, table-based HTML layouts for easy reading.

BI Readiness

Centralized Google Sheets structure easily connects to Looker Studio for macro-level error trend reporting.
