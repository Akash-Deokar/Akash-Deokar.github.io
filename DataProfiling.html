Data Preprocessing Suite

Automated Data Cleaning &
Feature Engineering

A comprehensive, interactive web application built in Python that empowers data scientists to visually inspect, clean, transform, and encode datasets without writing a single line of boilerplate code.

Core Modules

The suite is divided into six highly interactive modules that cover the entire standard machine learning data preparation phase. Each module provides real-time visual feedback.

1. Missing Value Handling

  • CCA: Auto-drops rows with < 5% missing data.
  • Basic Imputation: Mean/Median for numerical, Mode for categorical.
  • Advanced: KNN Imputation & MICE support.
  • Visuals: Pre vs. Post PDF & Boxplots.

2. Outlier Treatment

  • Z-Score: Detect based on customizable std dev thresholds.
  • IQR Method: Trim rows or cap values at boundary limits.
  • Percentile Capping: Cap extreme values at specific thresholds (e.g., 1st & 99th).

3. Feature Transformation

  • Math Transforms: Log, Reciprocal, Square, and Square Root functions to treat skewness.
  • Power Transforms: Box-Cox (for positive data) and Yeo-Johnson for achieving Gaussian distributions.

4. Feature Scaling

  • Standardization: StandardScaler (Centers mean to 0, std dev to 1).
  • Normalization: MinMaxScaler (Strict boundary of [0, 1]).
  • Robust Scaling: Uses median/quantiles to remain resilient to un-treated outliers.

5. Categorical Encoding

  • One-Hot Encoding: Convert nominal strings into binary dummy indicators.
  • Label Encoding: Target variable transformation.
  • Ordinal Encoding: Provide manual mapping dicts for categorical hierarchies.

6. Core Utilities

  • Dtype Conversion: Force columns to float, int, str, or datetime.
  • Structural Changes: Interactively drop useless columns or index rows.
  • Interim Export: One-click CSV download at any stage of the pipeline.

System Benefits

No-Code Interface

Accelerates EDA and preprocessing by completely eliminating repetitive pandas boilerplate code.

Immediate Visuals

Auto-plots pre/post distributions to instantly evaluate the impact of preprocessing decisions.

End-to-End Pipeline

Covers almost the entirety of the standard tabular machine learning data preparation phase.

Non-Destructive

Transformations happen in browser memory. Download interim steps without altering original source datasets.

Usage Guide

  1. 1
    Upload Data

    Navigate to the sidebar and upload any tabular .csv file into the app state.

  2. 2
    Select a Module

    Depending on your app's navigation, select the preprocessing step you want to perform (e.g., "Handle Missing Values" or "Scale Features").

  3. 3
    Interact & Tune Parameters

    Use Streamlit's multiselect boxes to choose target columns. Adjust specific parameters like Z-score standard deviation limits or KNN neighbor counts using the responsive sliders and input boxes.

  4. 4
    Evaluate & Export

    Review the updated DataFrame and visual metrics. Once satisfied, click the Download CSV button to save the cleaned data locally for your ML models.

Technology Stack

UI Framework: Streamlit Pandas NumPy Scikit-Learn Matplotlib & Seaborn SciPy

Local Setup & Installation

Prerequisite: Ensure you have Python 3.8+ installed on your local machine.

1 Clone the Repository

$ git clone https://github.com/your-username/data-preprocessing-suite.git
$ cd data-preprocessing-suite

2 Install Dependencies

It is highly recommended to use a virtual environment (venv).

$ pip install -r requirements.txt

If you don't have a requirements.txt file, run:

pip install streamlit pandas numpy scikit-learn matplotlib seaborn scipy

3 Run the Application

Start the Streamlit server to launch the interface in your default browser.

$ streamlit run app.py
